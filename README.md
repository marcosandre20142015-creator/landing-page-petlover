# 🐾 Landing Page de Alta Conversão - Clínica Veterinária PetLover

[![Vercel](https://shields.io)](https://pet-teal-iota.vercel.app/)
[![Status do Projeto](https://shields.io)](https://github.com/marcosandre20142015-creator/landing-page-petlover)

Este é um projeto focado em **cenário de mercado real**, desenvolvido como um estudo de caso para a clínica fictícia **PetLover**. O objetivo principal foi criar uma solução digital para resolver um problema crítico de conversão na captação de clientes para o novo plano de saúde pet da empresa.

---

## 🎯 O Desafio de Negócio
A clínica vinha investindo em anúncios pagos nas redes sociais (Instagram/Google Ads), porém direcionava todo o tráfego diretamente para o WhatsApp ou perfil institucional. Isso gerava um alto volume de usuários desqualificados, dúvidas repetitivas e perda de vendas por falta de informações claras sobre preços e coberturas.

### 💡 A Solução Desenvolvida
Desenvolvi uma **Landing Page de página única (Single Page)** estruturada com técnicas de conversão e copywriting para aquecer o lead antes do contato comercial:
* **Dobra Principal (Hero Section):** Proposta de valor clara e CTA (*Call to Action*) imediato.
* **Quebra de Objeções:** Seções detalhadas de benefícios, coberturas e tabela de planos transparente.
* **Gatilhos Mentais:** Prova social com depoimentos estruturados de clientes.
* **FAQ Interativo (Accordion):** Redução do suporte humano ao sanar as dúvidas mais frequentes de forma dinâmica.

---

## 🛠️ Tecnologias e Recursos Utilizados

Para garantir a máxima performance exigida em páginas de vendas profissionais, o projeto foi construído utilizando tecnologias nativas e limpas, sem dependências pesadas:

- **HTML5 Semântico:** Estruturação focada em acessibilidade e otimização para motores de busca (**SEO**).
- **CSS3 Moderno:** Utilização de *CSS Variables*, *Flexbox* e *CSS Grid* para um layout limpo, atraente e **100% Responsivo** (otimizado para dispositivos móveis).
- **JavaScript (Vanilla):** Lógica pura para o funcionamento do Accordion do FAQ e para o sistema de animações ao rolar a página (*Scroll Animation*).
- **Performance:** Imagens convertidas para o formato de última geração `.webp` e otimizadas para carregamento em menos de 2 segundos.

---

## 📈 Melhores Práticas Aplicadas

1. **Mobile-First Mindset:** Como mais de 80% dos acessos de anúncios vêm do celular, a interface foi desenhada prioritariamente para telas menores, garantindo botões de clique fáceis e leitura fluida.
2. **Intersection Observer API:** Animações nativas via JavaScript que surgem conforme o usuário rola a página, aumentando o tempo de permanência no site sem prejudicar o desempenho do carregamento.
3. **Clean Code:** Organização de arquivos estruturada para facilitar futuras manutenções ou escala do projeto.
